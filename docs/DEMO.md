# KerenScope — Demo Storyboard

Video = 30% skor. Ini bukan tambahan; ini fitur. Rencanakan seperti produk.

## A. Teaser (60 detik, public YouTube/sosmed)

Screen recording produk yang benar-benar jalan. Cut cepat, musik ringan, NO narasi panjang.

| Dtk | Scene |
|---|---|
| 0–5 | Terminal kosong → ketik: `keren "bank dengan fundamental terbaik di Indonesia?"` |
| 5–15 | Enter → banner KerenScope muncul → research objective muncul |
| 15–35 | Checklist plan mengisi satu per satu: company reports ✓ quarterly ✓ subsector ✓ foreign flow ✓ — terlihat agent BEKERJA |
| 35–50 | Report muncul: tabel perbandingan, bukti, "Confidence: 87%", disclaimer |
| 50–60 | End card: nama + tagline + "Built with Sectors API" + repo link |

Pesan yang harus kebawa: *one question in, researched report out — agent berpikir, bukan sekadar chatbot.*

## B. Judging video (maks 180 detik)

Bahasa Indonesia (boleh ID/EN — pilih yang paling natural buat presenter).

| Dtk | Segmen | Isi |
|---|---|---|
| 0–20 | Problem | "Riset satu pertanyaan pasar — misal membandingkan 3 bank besar — butuh belasan tab, file spreadsheet, dan berhari-hari. Investor retail & analis muda Indonesia gak punya waktu itu." |
| 20–35 | Intro produk | "KerenScope: agent riset keuangan otonom di terminal. Beri pertanyaan riset apa pun — ia menyelidiki sendiri pakai data Sectors." |
| 35–125 | **Demo live (inti)** | Jalankan `keren "bandingkan BBCA, BBRI, BMRI — mana yang fundamentalnya paling kuat?"` → tampilkan: (1) agent membuat plan, (2) langkah jalan satu per satu dengan data nyata, (3) VERIFY cross-check klaim, (4) report final + confidence + bukti tersitasi. Sambil jalan, voice-over menjelaskan fase: "ini plan… ini evidence… ini cross-check…" |
| 125–150 | How it works | Diagram singkat: PLAN → ACT → VERIFY → SYNTHESIZE; "13 purpose-built tools di atas Sectors API; loop orchestration-nya kami tulis dari nol di Go." Tunjuk README/repo sekejap. |
| 150–170 | Use cases lain | Flash: `keren research "saham consumer dengan revenue growth konsisten tapi valuasi rendah"` → plan yang BEDA muncul (bukti agent adaptif, bukan script). |
| 170–180 | Close | "Informasi & analisis — bukan rekomendasi investasi. KerenScope, built with Sectors." + repo URL |

**Catatan produksi:**
- Record di terminal resolution 1080p+, font size besar (terbaca di laybar HP).
- Script voice-over ditulis dulu, dry-run 2x sebelum record final.
- Durasi demo live: real run mungkin 3–5 mnt → time-lapse bagian ACT (keep beberapa step penting real-time), sisanya cut. JANGAN dipelankan palsu — ini tetap run asli, diedit.
- Panik button: kalau network bermasalah saat record, cache warm membuat run tetap deterministik.

## C. Sosmed post (wajib submission)

- Platform bebas (IG/LinkedIn/Threads/TikTok) — pilih yang audience-nya paling cocok (LinkedIn untuk juragan/investor, TikTok/Reels untuk reach).
- Wajib: tag akun resmi Sectors + pakai **thumbnail template** resmi (cek portal).
- Copy singkat: problem → 10-dtk GIF teaser → link repo. Hook: "Tanya apa pun soal saham Indonesia. Agent-nya yang riset."
